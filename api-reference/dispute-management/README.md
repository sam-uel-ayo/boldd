# Dispute Management

## Dispute Management

Query and resolve transaction chargebacks and card disputes programmatically to protect your store revenue.

{% hint style="warning" %}
Unresolved disputes will lead to automatic chargeback debits from your wallet balance. Monitor these endpoints regularly.
{% endhint %}

#### Available Endpoints

<table data-view="cards"><thead><tr><th>Endpoint</th><th>Description</th><th data-hidden data-card-target data-type="content-ref">Link</th></tr></thead><tbody><tr><td><strong>Fetch Disputes</strong></td><td>Query all transaction disputes logged against your charges.</td><td></td></tr><tr><td><strong>Accept a Dispute</strong></td><td>Acknowledge a chargeback claim and refund the customer.</td><td></td></tr><tr><td><strong>Decline a Dispute</strong></td><td>Challenge a chargeback claim using transaction evidence logs.</td><td></td></tr></tbody></table>
