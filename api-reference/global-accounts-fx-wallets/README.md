# Global Accounts (FX Wallets)

Establish international bank accounts in USD, EUR, and MXN under your customer profiles to receive international bank transfers.

{% hint style="info" %}
Global account creation requires a **Full KYC customer profile**. Ensure your customer has completed identity checks first.
{% endhint %}
