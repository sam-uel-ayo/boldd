# Universal Blacklist

Protect your platform from malicious actors and fraudsters using Boldd's Universal Blacklist API. This screening service checks customer identities, phone numbers, BVNs, and bank accounts against a unified, real-time database of flagged fraud profiles.

#### Key Capabilities

* **KYC Fraud Screening:** Automatically flag blacklisted BVNs or NINs during onboarding before they can transact.
* **Transaction Blocker:** Screen bank account numbers before initiating transfer payouts to prevent fraudulent transfers.
* **Risk Score Engine:** Receive real-time danger alerts for suspicious account activities based on merchant network data.
