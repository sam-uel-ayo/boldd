# Sub-Accounts & Multi-Tenancy

Model marketplace, agency, or corporate division structures by spawning sub-wallets programmatically under your primary merchant account.

{% hint style="info" %}
Sub-accounts can have their own payout profiles, allowing you to split revenues and settle funds directly to nested merchant accounts.
{% endhint %}
