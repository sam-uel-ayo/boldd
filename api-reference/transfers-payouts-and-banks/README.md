# Transfers, Payouts & Banks

Disburse funds to financial institutions across Nigeria instantly. Outward transfers require your account to hold a sufficient balance and have the `transfer` service grant active.

{% hint style="warning" %}
Always call **Validate Account Name** before executing a transfer to prevent disbursing funds to incorrect accounts.
{% endhint %}
