# Payouts / Settlements

Get a list of upcoming settlement payouts to your bank account.

**Endpoint**

<mark style="color:blue;">`GET`</mark> `{{base_url}}/business/payouts`

**Request Headers**

| Header          | Type     | Required | Description                                                  |
| --------------- | -------- | -------- | ------------------------------------------------------------ |
| `Authorization` | `String` | Yes      | Bearer token authentication (e.g. `Bearer YOUR_SECRET_KEY`). |
