# Virtual Cards

Issue and fund secure, spendable NGN and USD virtual debit cards for your customers with complete programmatic lifecycle control.

### Card Lifecycle Flow

{% stepper %}
{% step %}
#### Create Card Account

Establish the underlying cardholder profile. Create Card Account Guide
{% endstep %}

{% step %}
#### Cards Issuance

Generate the virtual card credentials. Cards Issuance Guide
{% endstep %}

{% step %}
#### Card Funding

Add funds to the card's spendable ledger. Card Funding Guide
{% endstep %}
{% endstepper %}
